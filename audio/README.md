# Audio Clips

Place short audio clips in this folder to use them with the `!clipname` command
in the main text box.

Examples:

- `!ding`
- `!alert`
- `!intro`

The app looks for common audio formats such as `.wav`, `.ogg`, `.oga`, `.flac`,
`.aiff`, `.aif`, and `.au`.

Formats that are not supported are intentionally left out so the app does not
need to generate extra conversion files or add extra work on each play.

The clip plays through the same output device as Piper TTS.
